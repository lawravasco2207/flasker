# ⚠️ Error Page Demo (404 & 500) — Python Web App

This is a simple Python web application built to **demonstrate custom error pages** for the two most common HTTP errors:

- **404 — Page Not Found**
- **500 — Internal Server Error**

It’s designed for beginners who want to learn how web servers handle and display errors in a user-friendly way using Python frameworks like **Flask**.

---

## 🧠 What You'll Learn

- How 404 and 500 errors occur in a web app
- How to **customize error pages** with HTML templates
- How to intentionally **trigger a 500 error** for learning
- Why proper error handling is important for user experience

---

## 🧰 Tech Stack

- **Language**: Python 3
- **Framework**: Flask (or FastAPI — easily swappable)
- **Frontend**: Basic HTML & CSS (for error templates)
